# MONDAY — FIGMA MAKE MASTER DESIGN PROMPT

## Version 0.1

### Design Direction: Digital Companion OS

Create a complete product design system and high-fidelity prototype for a web application called **Monday**.

Monday is not a chatbot.

Monday is a persistent digital companion designed to remember, reflect, learn, and grow alongside its user over months and years.

The experience should feel like:

* A living journal
* A personal operating system
* A trusted companion
* A calm workspace

Avoid making the product feel like:

* ChatGPT
* Claude
* Gemini
* Discord
* Slack
* Customer support software
* Enterprise dashboards

The user should immediately feel:

"Monday knows me."

---

# PRODUCT IDENTITY

## Core Concept

Monday exists to:

Remember.
Reflect.
Improve.
Repeat.

The product is built around four foundational systems:

1. Conversation
2. Memory
3. Goals
4. Reflection

Everything in the interface should reinforce these concepts.

---

# BRAND PERSONALITY

Monday should visually communicate:

* Intelligent
* Curious
* Calm
* Supportive
* Thoughtful
* Persistent
* Trustworthy

Avoid:

* Aggressive futurism
* Cyberpunk
* Neon aesthetics
* Hacker culture
* Overly corporate styling
* Gaming UI

The overall feeling should be:

"A digital companion that has been quietly growing alongside me for years."
